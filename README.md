# Yulsv--1

Proyecto desarrollado con Flask para la Actividad Clave 1 del submódulo Emplea frameworks para el desarrollo de software.

## Requisitos

- Python 3.12 o superior

## Instalación

1. Clonar el repositorio.
2. Crear el entorno virtual:

python -m venv .venv

3. Activar el entorno virtual:

Windows:
.venv\Scripts\activate

4. Instalar las dependencias:

pip install -r requirements.txt

## Ejecución

python app.py

Abrir el navegador en:

http://127.0.0.1:5000
